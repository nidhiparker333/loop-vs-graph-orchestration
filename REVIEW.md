# For reviewers

This is a small, self-funded experiment comparing two orchestration patterns on
one narrow task. It is not a study. Please attack it.

## What it claims

1. On this dataset, decision-based routing (graph) cost **+16.3% model calls and
   +5.8% tokens** versus a uniform iterative loop, for broadly equal quality.
2. The graph's genuine-invention rate was **1.8%** versus the loop's **5.6%**.
3. Of 89 outputs containing an invented content word, **89 passed the LLM
   rubric**, all scoring 2/2 on "groundedness".
4. Break-even for the graph on this task is **36% ambiguous inputs**; the
   dataset was 30%.

## What it does not claim

Anything about orchestration patterns in general, other tasks, other models, or
agents at large. One model, one prompt set, one dataset, one run at n=1,000.

## Things I already think are weak — please push here first

1. **Single run at n=1,000.** No run-to-run variance estimate. The within-run
   precision is good; stability is unmeasured.
2. **The ambiguous-input ratio (30%) is a design choice** and it sits just below
   the measured 36% break-even. Pick 40% and the token conclusion reverses. Is
   reporting the break-even enough to make this honest, or is the headline still
   misleading?
3. **The loop never really iterated** (`avg_iterations = 1.02`). The experiment
   therefore never tested a thrashing loop, which is the case that motivates the
   whole question. Is the comparison meaningful without it?
4. **The deterministic audit is my own construction.** It forgives plurals,
   substrings and unit words, so it under-reports. Does the `STRUCTURAL`
   allowlist in `audit.py` let real fabrications through? Tightening it moved
   the loop's rate from 30.0% to 10.0% — that is a large swing driven by my
   judgement.
5. **The dataset is synthetic and generated by me** (`generate_titles.py`). The
   `major_abbrev` style truncates words, and both workflows reconstruct them; I
   excluded those from the fabrication headline, which is a judgement call that
   moved the numbers materially.
6. **Same model generates and evaluates.** Claim 3 above is precisely a finding
   about how bad that is, yet the PASS/HUMAN_REVIEW rates still depend on it.
7. **Ground-truth MINOR/MAJOR labels are mine** and the classifier disagreed on
   181 of 999. I argue this does not affect cost (both routes are 3 calls).
   Check that reasoning.
8. **21 over-routes to human review** are counted against the graph, but the
   human-review cost model in the plain-English summary assumes $0.50/review,
   which is invented. The conclusion "graph wins above ~40c per bad title" rests
   on that.

## Reproducing

Needs an Anthropic API key. Roughly $7.50 for the 1,000-title run.

```
python experiment/generate_titles.py
python experiment/run_experiment.py --dataset titles_1000.json --runs 1 --condition scaled
python experiment/audit.py experiment/results/condition_scaled/run_1
```

The dataset is seeded, so `generate_titles.py` reproduces `titles_1000.json`
byte for byte.
